NoobToRoot / OldToRoot
======================

Jouer
  Double-clique sur index.html (clé USB, ordinateur, sans Internet).
  La pierre tombale en haut à droite ouvre OldToRoot (Fortran, COBOL, BASIC, Pascal, MS-DOS).
  Pour le web : dépose les 4 fichiers du jeu dans un dépôt GitHub et active GitHub Pages.

Fichiers
  index.html         NoobToRoot (Shell, Python, HTML)
  data.js            les questions de NoobToRoot (180)
  oldtoroot.html     OldToRoot, les langages d'avant
  data_old.js        les questions d'OldToRoot (200)
  NoobToRoot.xlsx    les deux banques dans Excel (onglets « questions » et « OldToRoot »)
  questions.csv      banque NoobToRoot, à importer dans Google Sheets
  questions_old.csv  banque OldToRoot, à importer dans Google Sheets
  csv_vers_data.py   regénère data.js et data_old.js

Modifier les questions
  Avec Excel :
    1. Ajoute ou corrige des lignes dans NoobToRoot.xlsx (une ligne = une question)
    2. python3 csv_vers_data.py NoobToRoot.xlsx   (convertit les deux onglets)
    3. Recharge la page
  Avec Google Sheets :
    1. Fichier > Importer > questions.csv
    2. Modifie, puis Fichier > Télécharger > .csv
    3. python3 csv_vers_data.py questions.csv   (ou questions_old.csv)

Colonnes
  langage      shell, python, html ; basic, msdos, cobol, pascal, fortran
  difficulte   1 facile, 2 moyen, 3 difficile
  reponse1     la correction affichée ; reponse2 à 6 = variantes acceptées
               une réponse qui commence par re: est une expression régulière
  leurre1/2    les deux mauvais choix du mode Pick
  indice       affiché en mode Hint
  explication  affichée après chaque réponse ; le code entre `backticks`

Tolérance à la saisie
  Espaces en trop et guillemets simples/doubles sont ignorés partout.
  Python : espaces autour des opérateurs et parenthèses ignorés.
  HTML : majuscules/minuscules ignorées, <br/> = <br>.
  Shell : la casse compte (ls ≠ LS), comme dans un vrai terminal.
  OldToRoot : majuscules/minuscules ignorées, sauf entre guillemets.
